# Site__Artist__Emily-Cruz
emily-cruz.artist.sovereignweb.site: Emily Cruz, actor-musician and artist. BA (Hons) Actor-Musician, Guildford School of Acting, 2026. Represented by Galloways.

Static files in `site/`, deployed to GitHub Pages from `dev`. No cookies, no tracking, no third-party scripts. Showreels are Spotlight embeds that load only when a visitor presses play.

- `tools/build.py` writes `site/index.html` and the five designs in `site/designs/` from one set of content. Edit the content there, then run `python3 tools/build.py`.
- Five designs, each built around an idea from her world: 1 Programme (live until Emily chooses), 2 Blue light, 3 Contact sheet, 4 Score, 5 Brief. `site/base.css` is shared; `site/designs/d1.css` to `d5.css` are the designs; `site/theme.css` is the chosen one (set `CHOSEN` in the build script).
- Images are WebP at 720 px (shown) and 1400 px (linked), with all metadata removed.
