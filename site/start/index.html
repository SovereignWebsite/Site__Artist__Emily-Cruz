Start here

Emily, this is your site. These steps hand it over to you, so you and your own Claude can change words, add photos and choose a design.

  1. Get a GitHub account

    If you do not have one, make one free at github.com/signup, and send Dinis the username.

  2. Accept both invitations

    Dinis invites you twice: to the SovereignWebsite organisation (as a member) and to your repository (with write access). Accept the organisation invitation at github.com/orgs/SovereignWebsite/invitation, because the link in GitHub's email may not offer an Accept button. Accept the repository one at the repository's invitations page. Claude's GitHub check needs both. You can push to the dev branch; every push publishes the site a minute or two later.

  3. Connect your Claude to GitHub

    In the browser or the Claude app: go to claude.ai/code, sign in, and follow the prompt to connect GitHub (GitHub asks you to authorise Claude). If Claude says it cannot reach the repository, accept both invitations and press "Check again". Then choose the repository SovereignWebsite/Site__Artist__Emily-Cruz and the dev branch. On your own computer instead: install Claude Code from its setup page. You never paste a token or password anywhere.

  4. Paste the prompt

    Paste the prompt from docs/prompt-for-your-claude.md into your Claude. It tells your Claude how the site is made and the rules it keeps to.

  5. Answer the questions

    Your Claude can go through docs/questions-for-emily.md with you: photo credits, a bio, your details, Instagram and TikTok, and which design you like.

  6. Choose a design

    Press "Choose a design" at the top of any page, or see all five side by side. Tell your Claude which one should be the home page.

What is here, file by file: docs/handover.md. Where every fact and photo came from: docs/sources.md.
